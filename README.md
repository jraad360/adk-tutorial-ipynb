# ADK Tutorial Notebook

This Jupyter Notebook follows the official [Google Agent Development Kit (ADK) Tutorial](https://google.github.io/adk-docs/get-started/tutorial/), which demonstrates how to build a multi-agent Weather Bot system.

- Note: only modification from the original is that API keys are loaded from a `.env` file instead of being hardcoded in the notebook.

## Tutorial Contents

The tutorial progressively builds a Weather Bot system that showcases:

- Basic agent creation with weather lookup functionality
- Multi-model support using LiteLLM
- Building an agent team with specialized sub-agents
- Adding memory and personalization with session state
- Implementing safety guardrails using callbacks

For the complete documentation, visit the [ADK Documentation](https://google.github.io/adk-docs/).
